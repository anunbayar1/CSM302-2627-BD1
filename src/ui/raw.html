1. Thread-үүдProducer thread тоо үүсгээд буферт хийнэ, consumer thread буферээс авна. Бүгд зэрэг, өөр өөрийн хурдаар ажиллана.
2. Хамгаалалтempty = сул нүд, full = дүүрсэн нүд. 0 болбол тухайн thread хүлээнэ. mutex нь нэг удаад нэг л thread-ийг буфер рүү оруулна.
3. НотолгооДоорх лог бол C програмын өөрийн хэвлэлт. Зогсоход «produced − consumed = буферт үлдсэн» таарвал нэг ч item алга болоогүй гэсэн үг.
